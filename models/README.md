# Trained Machine Learning Models

This folder is intended to contain the trained machine learning models and feature configuration files used by the Streamlit application.

The large serialized model files are currently stored locally and are not included in this repository because of their size.

To run the application, generate or obtain the required model files and place them in this folder. The filenames and feature configurations must match those expected by `app.py`.

See the project notebook for the data analysis and model development workflow.
